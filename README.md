## المكونات المجانية:
- Groq API (قصص + هوك)
- meta.ai (4 صور لكل مشهد)

## التركيب:
1. اعمل ريبو جديد وارفع الملفات
2. Settings > Secrets > Actions:
   - GROQ_API_KEY من console.groq.com
   - META_API_KEY (اختياري)
3. Actions > Run workflow
